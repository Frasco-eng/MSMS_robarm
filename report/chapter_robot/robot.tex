\section{Kinematic Chain Assembly}

\subsection{Power Bond Chain}

The mechanical power flows from the base (world frame, fixed) through the joints and links in sequence.
The base is connected to a \emph{world bond}: a fixed-velocity source that sets the inertial frame velocity to zero (Sf = 0 for all six components).

For each link $i = 1,\ldots,6$, the connectivity is:
\begin{center}
  Joint$_i$ (\texttt{twist\_ipp}) $\longrightarrow$ Link$_i$ (\texttt{wrench\_i})
  $\longrightarrow$ Link$_i$ (\texttt{wrench\_ipp}) $\longrightarrow$ Joint$_{i+1}$ (\texttt{twist\_i}).
\end{center}
After Joint$_6$ / Link$_6$, the distal power port terminates either in a free end (zero force source) or in the payload model.

\subsection{Signal Chain for Transformations}

The absolute transformation chain starts with $H_0 = I_4$ (the identity matrix, i.e.\ the world frame).
\begin{center}
  $H_0$ $\xrightarrow{\text{T\_prev}}$ Transf.$_1$ $\xrightarrow{\text{T\_next}=H_1}$ Transf.$_2$ $\xrightarrow{H_2}$ $\cdots$ $\xrightarrow{H_6}$ GravityTerm.
\end{center}
Each \texttt{Transformation} block also sends \texttt{T\_next} to the \texttt{MSe} element of the corresponding \texttt{Link} block (for gravity orientation) and to the 3-D visualisation.


\section{Global Causality Analysis}

The complete robot model uses exclusively \emph{integral causality} for the six I-elements in the Link Body sub-models, which is achievable because:
\begin{itemize}
  \item The world bond imposes velocity (effort-out causality at the base).
  \item Each \texttt{Joint} transmits this causality to the next \texttt{Link}.
  \item The revolute constraint removes five out of six DoF per joint.
  \item The single free DoF (rotation about $z$) is driven by the actuator effort source.
  \item The non-linear C element in the harmonic drive retains integral causality.
\end{itemize}
No derivative causality is required in the final assembled model, which ensures numerical stability of the ODE integration.

\section{Payload Model}

A point-mass payload $m_{\text{load}}$ attached at the end-effector (Link~6's distal port) is modelled as an additional \texttt{Link} block with:
\begin{itemize}
  \item $m = m_{\text{load}}$,
  \item $J = \text{diag}(\epsilon,\epsilon,\epsilon)$ (very small inertia tensor to avoid numerical singularities),
  \item $r_{Gp} = [0,0,0]^T$ (mass at the attachment point).
\end{itemize}
The distal port of the payload terminates in a zero-wrench source.

\section{3-D Visualisation}

The 20-sim 3-D Mechanics toolbox receives the pose signals \texttt{pose\_abs} and the rotation matrices from each \texttt{Transformation} block.
Cylinder primitives are created for each link, positioned and oriented according to the absolute transformation, giving a real-time animated view of the robot posture during simulation.
