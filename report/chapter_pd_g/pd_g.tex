\section{Manipulator Dynamics and Control Objective}

The equations of motion of an $n$-link robot manipulator can be written in the joint space as a set of nonlinear, coupled differential equations:
\begin{equation}
  M(q)\ddot{q} + C(q,\dot{q})\dot{q} + D\dot{q} + g(q) = \tau
  \label{eq:manipulator_dyn}
\end{equation}
where $n=6$ for the UR5 manipulator. The terms appearing in \cref{eq:manipulator_dyn} represent:
\begin{itemize}
  \item $q \in \mathbb{R}^{6\times1}$ is the vector of joint positions (angular displacements) $[\text{rad}]$.
  \item $\dot{q} \in \mathbb{R}^{6\times1}$ is the vector of joint velocities $[\text{rad/s}]$.
  \item $\ddot{q} \in \mathbb{R}^{6\times1}$ is the vector of joint accelerations $[\text{rad/s}^2]$.
  \item $M(q) = M(q)^\top \succeq 0 \in \mathbb{R}^{6\times6}$ is the joint-space inertia matrix $[\text{kg}\cdot\text{m}^2]$.
  \item $C(q,\dot{q}) \in \mathbb{R}^{6\times6}$ is the matrix accounting for Coriolis and centrifugal forces $[\text{kg}\cdot\text{m}^2/\text{s}]$.
  \item $D = D^\top \succeq 0 \in \mathbb{R}^{6\times6}$ is the matrix of viscous friction coefficients $[\text{kg}\cdot\text{m}^2/\text{s}]$.
  \item $g(q) \in \mathbb{R}^{6\times1}$ is the vector of generalized torques due to gravity $[\text{N}\cdot\text{m}]$.
  \item $\tau \in \mathbb{R}^{6\times1}$ is the vector of generalized torques applied by the joint actuators $[\text{N}\cdot\text{m}]$.
\end{itemize}

The control objective is to globally asymptotically stabilize the joint position vector $q$ to a desired constant target configuration $q^* \in \mathbb{R}^{6\times1}$. Since the target configuration is stationary, the reference velocity profile is identically zero.

\section{Control Law}

To fulfill the control objective, the centralized control torque vector $\tau$ is chosen as:
\begin{equation}
  \tau = K_p (q^* - q) - K_d \dot{q} + g(q)
  \label{eq:pd_control_law}
\end{equation}
where:
\begin{itemize}
  \item $K_p = K_p^\top \succeq 0 \in \mathbb{R}^{6\times6} $ is the matrix containing the proportional gains $[\text{N}\cdot\text{m/rad}]$.
  \item $K_d = K_d^\top \succeq 0 \in \mathbb{R}^{6\times6}$ is the matrix containing the derivative gains $[\text{N}\cdot\text{m}\cdot\text{s/rad}]$.
\end{itemize}
The control law consists of a proportional action tracking the regulation error, a derivative action acting directly on the measured joint velocity $\dot{q}$ to inject damping, and a nonlinear feedforward term providing compensation for the gravitational torques.

\section{Bond-Graph Implementation}

Each \texttt{PD} block within the 20-sim library acts as a single-joint decentralized execution unit. It processes continuous signal flows and converts them into an output command. The block maps the control law component-wise for a single joint index $i$:
\begin{equation}
  \tau_i = K_{p,i}(q_i^* - q_i) - K_{d,i}\dot{q}_i + \tau_{g,i}
\end{equation}
The sub-model handles the following external interfaces:
\begin{itemize}
  \item It receives the vector signal \texttt{Q} = $[q_i, \dot{q}_i]^T$ from the physical \texttt{Joint} block.
  \item It receives the scalar gravity feedforward signal \texttt{gravity} = $\tau_{g,i}$ from the centralized computing unit.
  \item It outputs the scalar signal \texttt{tau} directed to the effort source modulating the joint's actuator.
\end{itemize}

The signal processing sequence within the block is structured as follows:
\begin{enumerate}
  \item A local \textbf{Constant} block defines the reference configuration parameter $q_i^*$.
  \item A \textbf{PlusMinus} junction computes the scalar tracking position error $e_i = q_i^* - q_i$.
  \item A \textbf{Gain} block multiplies the error vector $[e_i, \, -\dot{q}_i]^T$ by the localized parameters matrix $K_i = [K_{p,i}, \, K_{d,i}]$ to construct the tracking control action.
  \item A final summation node adds the signal coming from the gravity feedforward line, routing the definitive scalar command $\tau_i$ to the output port.
\end{enumerate}

\section{Gravity Compensation}

\subsection{Closed-Form Gravity Torque}

The gravitational vector $g(q)$ is generated from the potential energy distribution of the multi-body system. For any joint $i$, the required static torque $\tau_{g,i}$ is determined by accumulating the moments produced by all subsequent links $j \geq i$. 

To handle variable tool configurations, the mass profile of the final link is adjusted to incorporate the mass of the end-effector payload: $m_6' = m_6 + m_{\text{load}}$. The generalized gravity torque is evaluated through the vector cross-product equation:
\begin{equation}
  \tau_{g,i} = \sum_{j=i}^{6} m_j\, g^T \left(z_{i-1} \times (p_{G,j}^0 - p_{i-1}^0)\right),
  \label{eq:gravity}
\end{equation}
where:
\begin{itemize}
  \item $g = [0, \, 0, \, -9.81]^T \in \mathbb{R}^{3\times1}$ is the static acceleration gravity vector defined in the base reference frame.
  \item $z_{i-1} \in \mathbb{R}^{3\times1}$ is the orientation vector of the joint actuation axis, extracted as the third column of the homogeneous transformation matrix $T_{i-1}$.
  \item $p_{G,j}^0 \in \mathbb{R}^{3\times1}$ is the coordinates vector specifying the absolute position of the center of mass of link $j$.
  \item $p_{i-1}^0 \in \mathbb{R}^{3\times1}$ is the absolute position vector of the origin of coordinate frame $i-1$.
\end{itemize}

\subsection{Implementation in the GravityTerm Block}

The \texttt{GravityTerm} block coordinates the computation of the feedforward variables across all joints. It operates entirely as a mathematical \emph{signal} block, meaning it contains no power bonds and does not impose causality constraints during the model resolution.

The structural transformations $T_1$ through $T_6$ enter the block as $4\times4$ matrices from the kinematic transformation chain. For each link index $j$, the translation parameters and spatial vectors are mapped according to the following operations:
\begin{align}
  p_j^0     &= T_j[1\!:\!3, \, 4], \\
  p_{G,j}^0 &= T_j[1\!:\!3, \, 1\!:\!3]\cdot r_{\text{gp},j} + p_j^0, \\
  z_j       &= T_j[1\!:\!3, \, 3].
\end{align}
The block computes the individual scalar outputs \texttt{tau\_1} through \texttt{tau\_6} executing the vector additions defined in \cref{eq:gravity}. The outputs are packed into the vector signal \texttt{tau\_g} $\in \mathbb{R}^{6\times1}$ and forwarded to the respective controllers.
